## 腾讯云负载均衡是免费的吗？先把账单拆成四块

不是。负载均衡不是默认免费的服务，账单通常由四块组成：负载均衡套餐或实例费、公网网络费、容量费，以及后端资源费。任何一块都可能让你的“免费”预期落空。

- **负载均衡套餐/实例费**：ALB 公测期 0 元/小时；GWLB 已正式商用，0.098 元/个/小时；CLB 产品页展示的广州 1Mbps 套餐是 167 元/月。不同产品线、地域、规格价格不同。
- **公网网络费**：公网访问会产生带宽或流量费。ALB 的公网网络费由弹性公网 IP（EIP）正常收取；内网访问不经过公网，通常没有这一项。
- **容量费**：ALB 按 ALCU 计费，公测期免；CLB 按量计费涉及 LCU 费，产品页当前写的是新购按量计费 LCU 费下调 18%。
- **后端资源费**：CVM、数据库等。负载均衡只负责转发流量，不能处理请求，你至少需要一台后端服务器。

> 负载均衡只负责转发流量，不能处理请求。只买负载均衡，它还跑不起来业务。

最后一条最容易被忽略。很多人比价时只盯着负载均衡的 0 元或 167 元，却忘了后端 CVM 从创建那一刻就在计费。负载均衡只是流量入口，不是“买了就能跑业务”的完整方案。

## 哪些情况其实不需要买腾讯云负载均衡

只有一台后端服务器、没有高可用要求、也不需要七层转发的个人站点，直接绑定 EIP 更省。负载均衡解决流量分发和单点故障，没有这些需求就不必上。

- **单机小站**：一台 CVM 加一个 EIP 就能对外服务，再加 CLB 会多一层配置和一笔费用。
- **没有后端服务器**：负载均衡不能处理请求，先买 CVM 部署业务，再考虑要不要加负载均衡。
- **只需要 HTTPS 证书**：单机直接装证书就行，不必为了 SSL 卸载上负载均衡。
- **只有一个后端、也不需要负载分担**：内网 CLB 也是多余，直接把服务地址写死更简单。

判断标准很简单：你有没有两台以上后端、有没有高可用要求、有没有七层路由或灰度发布需求。三个都没有，先别买。
